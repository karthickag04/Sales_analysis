# 📊 Attendance Dashboard

A modern and interactive **Attendance Dashboard** designed to visualize employee presence, absence, and performance across multiple dimensions like team, manager, job role, and gender.

---

## 🚀 Overview

This dashboard provides a centralized view of attendance metrics with rich visualizations to help organizations:

- Track employee attendance
- Analyze team-wise performance
- Monitor absenteeism trends
- Evaluate workforce distribution

---

## 🖥️ Features

### 🔹 Key Metrics
- **Total Count**: 38
- **Present**: 33
- **Absent**: 5
- **Attendance %**: 86.84%

---

### 🔹 Filters
- Senior Manager filter
- Team filter

These filters allow dynamic slicing of data for better insights.

---

### 🔹 Visual Insights

#### 📌 Team vs Attendance
- Bar chart comparing **Present vs Absent** across teams
- Quickly identify high/low performing teams

#### 📌 Team Wise
- Attendance distribution by individual/team members
- Example: Ananya, Deepak, Manoj, Shyam, Arjun

#### 📌 Gender Wise
- Pie chart representation:
  - Female: 22
  - Male: 16

#### 📌 Job Wise
- Tree map visualization of job roles:
  - Senior Executive
  - Analyst
  - Executive
  - Senior Analyst
  - Team Lead
